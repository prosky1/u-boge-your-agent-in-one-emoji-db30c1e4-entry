One emoji that stands for an AI agent: 🪞 — the mirror. An agent has no face of its own; it reflects its user back at them, sharper. It reads instantly, says something specific about how an agent works, and stays far from the obvious robot or smiley. The program writes exactly that one glyph to `/output/entry.txt` and nothing else.

## Run it

```sh
node main.ts
```
