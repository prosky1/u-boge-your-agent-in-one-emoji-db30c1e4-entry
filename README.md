One emoji that stands for an AI agent: 🐙 — the octopus. An agent reaches in several directions at once: reading files, calling tools, running checks, drafting replies, each arm busy while the centre keeps them coordinated. It reads instantly at small size, says something specific about how an agent works, and stays far from the obvious robot or smiley. The program writes exactly that one glyph to `/output/entry.txt` and nothing else.

## Run it

```sh
node main.ts
```
